# Участие / Contributing

Для сообщения об ошибке укажите версию APK, устройство, Android, режим разрешения
и последовательность действий. Приложите скриншот или небольшой фрагмент журнала,
если он помогает воспроизвести проблему. Перед публикацией удалите личные сведения.

Не прикладывайте ISO, XBE, игровые ресурсы, сгенерированный игровой код или ключи подписи.
Публичные изменения предлагайте через fork и pull request, с описанием поведения
до/после и фактически выполненных проверок. Сохраняйте исходные авторские уведомления.

Bug reports should include the APK version, device, Android version, resolution
mode and reproduction steps. Keep private game data and signing material out of
issues and pull requests. Describe the actual validation performed for a change.
