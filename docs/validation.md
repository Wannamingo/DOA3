# Проверка alpha4 / Alpha4 validation

12 октября 2026 года на RG477M проверены:

- Выбор ISO через Android SAF; ZIP в системном выборе недоступен для выбора.
- Проверка размеров и SHA-256 всех 24 файлов (4 191 140 992 байта) без распаковки.
- В приложении сохранена таблица ISO размером 1 516 байт; физическая папка `iso-disc` не создаётся.
- Нативный диск D: открывает файлы по виртуальным путям `iso-disc`; XBE также читается из образа.
- Заставки, игровое меню, выбор персонажа, бой, игровая пауза и возврат в лаунчер.
- После завершения процесса и повторного запуска выбранный ISO доступен без повторного выбора или полной проверки.
- ARM64-тест: смещения >4 ГиБ, независимые курсоры, EOF, атрибуты и каталог, запрет записи, отказ при неверных границах и повторных именах. Обычный файловый ввод-вывод сохранений продолжает работать.
- Лаунчер на четырёх размерах экрана и RU/EN, без ZIP в интерфейсе и справке.
- Подпись APK, выравнивание 16 КиБ и совпадение SHA-256 установленного APK.

Отчёт: [iso-validation.json](iso-validation.json). Полное прохождение не проверялось.
Предыдущие отчёты сохранены ниже и описывают соответствующие версии.

## Базовая проверка alpha1 / Alpha1 baseline

Проверка выполнена 11 октября 2026 года на RG477M: Android 14 / GammaOS,
Mali-G615 MC6, экран 1280×960.

| Проверка | Результат |
| --- | --- |
| Импорт исходного полного USA ISO через системный выбор файлов Android | Успешно |
| Проверка всех файлов ISO точным Java-классом из APK | 24 файла, 4 191 140 992 байта; размеры и SHA-256 совпали |
| Запуск игры, заставки, меню и бой | Проверено на устройстве |
| Ввод, пауза и возврат в лаунчер | Проверено |
| Звуковой вывод | Ненулевой аудиопоток; отдельная оценка качества звука не выполнялась |
| Режимы 2× и 3× | Работу подтвердил владелец устройства |
| Финальный режим 3× | Журнал: `2160x1440 scale=3 guest=720x480` |
| Исходные пропорции | Журнал: `viewport=0,0,1280,960`, `aspect=source (4:3)` |
| ARM64 SIMD, SHA, транзакционные сохранения | Тесты завершились с кодом 0 |
| Fiber и вызовы Android на зарегистрированном стеке потока | 20 000 переключений, код 0 |
| HLSL→GLES и аппаратное чтение пикселей | Тесты прошли на Mali-G615 MC6 |
| Лаунчер | Три разрешения, сохранение настроек, блокировка импорта, четыре размера окна |
| Подпись APK и выравнивание 16 КиБ | Проверено |

Частота кадров меняется при загрузке и между сценами. Краткие наблюдения около
60 FPS не подтверждают постоянные 60 FPS во всех режимах. Полное прохождение,
все персонажи, арены и эффекты не проверены; отдельные команды рендера могут пропускаться.

Machine-readable results: [validation.json](validation.json).

This is an alpha validation record, not a complete compatibility or performance
certification. The device owner confirmed 2×/3× operation; library tests and a
single gameplay session do not establish full-game completion.
