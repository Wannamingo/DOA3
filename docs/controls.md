# Управление / Controls

## Назначение кнопок

Откройте **Настройки → Назначение кнопок → Настроить**. Вкладки «Экранные кнопки»
и «Геймпад» хранят независимые раскладки. Выберите действие Xbox напротив нужной
кнопки: A/B/X/Y, Black/White, LT/RT, Start, Back, нажатия стиков, направления
крестовины, меню приложения или «Не назначено». Изменения сохраняются сразу и
применяются при следующем запуске игры. Несколько кнопок могут иметь одно действие.

Подписи экранных кнопок отражают назначенные действия. Физические A/B/X/Y указаны
по расположению Xbox: A снизу, B справа, X слева, Y сверху. Индивидуальное назначение
имеет приоритет над общей перестановкой A/B и X/Y. «Сбросить раскладку» сбрасывает
только выбранную вкладку.

Левый стик, экранный и физический, дублирует крестовину, включая диагонали.
В центре действует мёртвая зона; назначения направлений крестовины учитываются.
Правый стик сохраняет самостоятельный аналоговый ввод.

По умолчанию Start открывает игровую паузу, Select — меню приложения. Постоянная
экранная кнопка ≡ и системная кнопка «Назад» сохраняют доступ к меню после
переназначения Select.

## Расположение экранных элементов

1. Во время игры нажмите маленькую кнопку **с карандашом рядом с FPS**.
2. Игра встанет на паузу. Перетаскивайте крестовину, стики и отдельные кнопки.
3. Нажмите **«Сохранить»**, чтобы применить расположение и продолжить игру.

«Отмена» возвращает положение до открытия редактора. «Сбросить» восстанавливает
стандартное расположение в текущем сеансе редактирования: его можно сохранить или
отменить. Start на геймпаде сохраняет расположение; Select или «Назад» отменяет.
При сворачивании приложения незавершённое редактирование отменяется.

Расположение сохраняется между запусками, учитывает относительные координаты
экрана и не позволяет унести элемент за край. Кнопка редактора остаётся доступной
при скрытом экранном управлении; в редакторе элементы показываются временно.
Чтобы видеть их постоянно, выберите **Экранные кнопки → Показывать** в настройках.

## English

Open **Settings → Button assignments → Configure** for independent touch and
gamepad layouts. Select an Xbox action for each source button. Assignments save
automatically and apply on the next game launch. Individual gamepad assignments
override the general A/B and X/Y swap. Reset affects only the selected layout.
The left stick duplicates all eight D-pad directions, respecting their assignments.

Tap the small **pencil next to FPS** during gameplay to edit positions. The game
pauses while you drag individual controls. Save resumes with the new layout;
Cancel restores the previous positions. Reset restores the default positions as
an editable draft. Gamepad Start saves; Select or Android Back cancels. Leaving
the app cancels an unfinished edit. Saved positions survive game restarts.

The pencil remains available when touch controls are hidden. Editing temporarily
shows all controls; select Touch controls → Show to keep them visible during play.
